Befund

Was an der heutigen Karte auffällt

Animation

Die Punkte starten ständig neu

Die Karte zeichnet ihr SVG bei jeder Änderung von 13 Sensoren neu (triggers_update). Zwischen 20:20:00 und 20:21:00 Uhr kamen allein von TV 10 und von Server 26 Änderungen, also etwa alle 2 Sekunden eine. Jedes neue SVG startet die SMIL-Animation bei 0. Weil eine Runde 2,6 bis 2,8 s dauert, erreichen die Punkte ihr Ziel oft gar nicht.

Dasselbe Verhalten ist im Repo schon für die Hausgeräte-Animation festgehalten: Dort liefert die Vorlage bewusst gleichen HTML-Text, damit nichts neu startet.

Animation

Tempo und Strichstärke sagen fast nichts

Die Umlaufzeit fällt linear von 2,8 s (bis 50 W) auf 1,2 s (ab 2.500 W). Im Screenshot liegen die Verbraucher zwischen 6 und 348 W, also zwischen 2,80 s und 2,61 s. Die Leitungen sind immer 1,8 Einheiten breit, die Punkte immer 3.

Weil alle Verbraucherleitungen im selben Punkt beginnen und fast gleich schnell sind, laufen ihre Punkte als waagerechte Reihe. Im Screenshot ist sie direkt unter dem Haus zu sehen.

Die 350 px sind aus dem Screenshot geschätzt. Bei einem breiteren Tablet-Layout entschärft sich das.

Vorschläge

Was sich ändern würde

Alle Punkte stecken im Vorschlag oben. Sie sind unabhängig voneinander umsetzbar. Die Reihenfolge entspricht dem Nutzen.

Animation

1 · Durchgehender Fluss statt Neustart

Die Phase der Animation wird aus der Uhrzeit berechnet (negativer animation-delay). Ein neu gezeichnetes SVG setzt deshalb genau dort fort, wo das alte war. Tempo und Breite sind in sechs Stufen gerastert, damit ein Sprung von 427 auf 431 W nichts verändert.

Animation

2 · Leuchtstriche, deren Breite und Tempo zur Leistung passen

Statt drei Punkten laufen kurze, abgerundete Lichtstriche auf einer getönten Leitung. Breite und Tempo wachsen logarithmisch mit der Leistung, so unterscheiden sich 6 W und 427 W auf einen Blick. Die Tabelle unten nennt die Werte.

Animation

3 · Ein Puls nur an der Hauptquelle

Die Quelle, die gerade den größten Teil liefert (jetzt: Netz), sendet alle 2,8 s einen weichen Ring aus. Mehr bewegt sich an den Knoten nicht. „Bewegung reduzieren“ zeigt ein Standbild mit stehenden Strichen.

Darstellung

4 · Ringe zeigen Messwerte

Akku: der Ring füllt sich mit dem Ladestand, das Symbol zeigt ihn auch. Solar: Anteil an der höchsten gemessenen Leistung (1.828 W, Juni 2026). Haus: Quellenmix aus Netz, PV und Akku. Verbraucher: Anteil am Hausverbrauch, zusätzlich als Prozentzahl unter dem Namen.

Darstellung

5 · „Sonstige“ und höchstens sechs Verbraucher

Der nicht zugeordnete Rest bekommt einen neutralen Knoten. Sind es mehr als sechs Knoten, bleiben die fünf größten stehen und der Rest wandert in „Sonstige“. So haben auch lange Namen wie „Hausgeräte“ Platz. Die Zahl der zusammengefassten Verbraucher steht als „+n“ unter „Sonstige“. Jetzt betrifft das nur den Schreibtisch mit 6 W; zieht er wirklich Strom (Wochenmittel 23–99 W, Spitzen um 520 W), ist er von selbst unter den fünf größten.

Darstellung

6 · Gebogene Leitungen mit eigenen Ansatzpunkten

Jede Verbraucherleitung beginnt an einer eigenen Stelle des Hausrings und läuft als Kurve nach unten. Die Verbraucher sitzen auf einem flachen Bogen. Inaktive Quellen bekommen eine gestrichelte, fast unsichtbare Leitung.

Umsetzung

So käme es in die Karte

  1. energie-flow-karte.yaml: Die Struktur bleibt (vertical-stack mit Kopf-button-card, picture-elements samt Klickflächen), dazu kommt die Tageszeile als dritte button-card. Keine neue Karte aus HACS nötig.
  2. Die SMIL-Punkte (animateMotion) sind Pfade mit stroke-dasharray. Keyframes und die Regel für prefers-reduced-motion liegen in extra_styles.
  3. Neu in triggers_update: sun.sun, sensor.solarbank_3_e2700_pro_akkuenergie, number.solarbank_3_e2700_pro_soc_minimum (statt 10 % fest) und die vier Tageswerte (sensor.pv_anlage_taglicher_hausverbrauch, …_tagliche_netznutzung, …_tagliche_pv_hausabgabe, …_tagliche_akku_hausabgabe).
  4. energie-verbrauch-uebersicht-karte.yaml: Heizung Petrol (Live-Kachel und Rangliste), Schreibtisch Violett, Gartenpumpe Limette.
  5. Geprüft mit allen Checks aus ci/README.md und einem Rendertest der Vorlagen mit sieben Fällen, darunter ausgefallene Sensoren und Verbraucher, die zusammen mehr melden als das Haus.
// Phase an der Uhr: neu gezeichnete SVGs laufen nahtlos weiter
const n   = (w) => Math.max(0, Math.min(1, Math.log10(1 + w/10) / Math.log10(301)));
const lvl = (w) => Math.round(n(w) * 5);                 // 0..5
const SPEED = [16, 26, 36, 48, 60, 74];                  // px/s
const flow = (d, c, w) => {
  const dur = (28 / SPEED[lvl(w)]).toFixed(2);           // Periode 28 = Strich + Lücke
  const ph  = ((Date.now() / 1000) % dur).toFixed(2);
  return `<path d="${d}" class="ef-flow" stroke="${c}" stroke-width="${1.5 + lvl(w) * 0.5}"
    stroke-dasharray="${7 + lvl(w)} ${21 - lvl(w)}" stroke-linecap="round" fill="none"
    style="animation-duration:${dur}s;animation-delay:-${ph}s"/>`;
};

# extra_styles
@keyframes ef-flow { to { stroke-dashoffset: -28; } }
.ef-flow { animation: ef-flow linear infinite; }
@media (prefers-reduced-motion: reduce) { .ef-flow, .ef-pulse { animation: none; } }
